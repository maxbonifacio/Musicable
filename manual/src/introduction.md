# Introduction

Musicable is a free, open-source digital audio workstation for writing,
recording, editing and mixing music. Its workflow is modelled on Ableton
Live's arrangement view, so Live users will find their way around, and its
default keys follow Live's where Live has one.

> Musicable is pre-alpha. It records audio and MIDI (MPE too) into takes
> you can comp, arranges clips, edits notes in a piano roll, plays CLAP and
> VST3 plugins and eight devices of its own, mixes with groups, sends and
> returns, automates, undoes and redoes anything, lets you change any key,
> and exports mixdowns and stems faster than real time. Expect rough edges,
> and keep backups of your projects.

Windows is the first platform Musicable supports. It builds on macOS and
Linux too, but it's tested much less there.

## This manual

- **Getting started** installs Musicable and sets up your audio.
- **Using Musicable** goes through the window and how to record, edit, mix,
  automate and export.
- **Built-in devices** has a page for each of Musicable's own devices.
- **Customising** covers keys, the mouse, themes, workspaces and profiles.
- **Reference** lists every command and every default key, and how to run
  Musicable from the command line.

Chapters in grey are planned and not written yet.

Keys are written as on Windows, such as Ctrl+S. Every key can be changed,
so this manual gives the default ones.

## Getting help

Musicable is made on GitHub at
[maxbonifacio/Musicable](https://github.com/maxbonifacio/Musicable). To
report a bug, or to ask for something, [open an
issue](https://github.com/maxbonifacio/Musicable/issues) there. The edit
button at the top of each page of this manual opens the page on GitHub, so
you can suggest a fix.
