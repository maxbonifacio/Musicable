# About this manual

This manual is part of Musicable's source code, in the `manual` folder, and
changes with it: a change to Musicable that you'd notice comes with the
change to its page. The lists of commands, keys and device controls are
made from the code itself.

To suggest a fix, use the edit button at the top of a page, or [open an
issue](https://github.com/maxbonifacio/Musicable/issues).
[CONTRIBUTING.md](https://github.com/maxbonifacio/Musicable/blob/main/CONTRIBUTING.md#the-manual)
says how the manual is written and built.
