# Default keys

The keys Musicable starts with. They follow Ableton Live's keys where Live
has one, so Live users will find them familiar. [Every command](commands.md)
lists the same keys menu by menu.

Most keys work everywhere. Some work in one panel only, while it has the
focus, and there they win over what the key does everywhere else: the arrow
keys move notes in the piano roll, and step through the undo history in the
History panel, and 0 bypasses the devices selected in the devices panel.
Click in a panel to give it the focus.

Keys are written as keymap files write them: Period is the `.` key, Comma
the `,` key, Equals the `=` key and Minus the `-` key. You can change any of
them on the Settings window's Keys page (**Options > Keyboard Shortcuts**,
Ctrl+K).
